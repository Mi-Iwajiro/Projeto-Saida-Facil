# Projeto-Saida-Facil
Projeto para o Soluciona SESI, onde nosso intuito é agilizar a maneira que é feita as autorizações de saída da escola, permissões de contra turno e pedidos de liberação.

<QUAL É A NOSSA META???>
Nossa meta com o projeto é evitar imprevistos na hora da realização de trabalhos que precisem de uma autorização de utilização do ambiente escolar, de forma simples e de forma rápida, assim evitando possíveis conflitos entre a escola e o aluno.

--REQUISITOS--
Para que o site funcione sem nenhum problema é preciso que tenha na sua máquina o NodeJs - https://nodejs.org/pt-br
*Para que seja possivel o teste do site é preciso que tenha um dispositivo como servidor
*Para iniciar o servidor local basta digitar a seguinte linha no terminal: node server.js. após isso o site já estará aberto para testes
